Step-by-step setup guide (about 10 minutes) ShowHide
  1. Create your Razorpay account

    Sign up at razorpay.com. Test mode works immediately. To accept real money, complete your business verification (KYC) in the Razorpay Dashboard. This usually takes 1–3 working days.

  2. Start in Test mode

    In the Razorpay Dashboard, switch the toggle at the top to Test Mode. Test mode uses fake money, so you can try everything safely.

  3. Generate your API keys

    Go to Account & Settings → API Keys → Generate Key. Copy the Key ID and Key Secret. The secret is shown only once, so paste it somewhere safe.

  4. Paste the keys below and save

    Fill in API Key ID and API Key Secret in the form below, click Save Payment Settings, then click Test connection above. You should see "Your keys work".

  5. Add a webhook in Razorpay

    This is how Razorpay tells this app that a customer has paid. Go to Account & Settings → Webhooks → Add New Webhook and fill in:

    • Webhook URL: copy this exactly:
      {{ webhook_url }}
    • Secret: click below to create a strong secret, copy it into Razorpay. It's also filled into the form below for you.
      Click "Generate" to create a secret
    • Active Events: tick only payment_link.paid, then save the webhook.
  6. Save the same secret here

    Make sure the Webhook Secret field below has exactly the secret you entered in Razorpay, then click Save Payment Settings.

  7. Make a test payment

    Open any quotation with a balance due and click Generate Payment Link. Open the link and pay using Razorpay's test UPI ID success@razorpay. Within a few seconds the payment should appear on the quotation as Razorpay Auto.

  8. Go live

    Once your KYC is approved, switch Razorpay to Live Mode and repeat steps 3–6: live mode has its own API keys and its own webhook. Save the live keys and secret here, then click Test connection. The badge at the top will say LIVE mode.

Razorpay sometimes renames menu items. If you can't find one, search for it in the Razorpay Dashboard.
