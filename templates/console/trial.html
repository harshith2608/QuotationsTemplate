Features

{% if boq %}
How they price · {{ 'by item (BOQ lines)' if boq.on else 'by material' }}

By material: a rate per sqft for each material and work type, sizes on each item, fittings from a price list (modular / carpentry firms). By item: each item with its own rate, description and unit (wardrobe per sqft, side table per piece, 3D design lump sum), printed as a BOQ (turnkey firms). The business can also choose this in Settings → Pricing. Quotations already made stay as they are.

{% if not boq.ready %}

Pricing by item needs the latest database update first (Updates → Update all).

{% endif %}
Photos on items · {{ 'on' if boq.photos.on else 'off' }}

A reference photo on any line of a quotation (a sofa, a chair, a wardrobe design), optional: a small "Photo" button under each item's name. Printed in a Photo column of the quotation PDF and shown on the quotation page and the customer's link. Turning it off hides the button; photos already on quotations stay.

{% if not boq.photos.ready %}

Needs the latest database update first (Updates → Update all).

{% endif %}
GST on quotations · {{ ('on, ' ~ ('%g' % boq.gst.rate) ~ '%') if boq.gst.on else 'off' }}

Quotations show their total, then GST at this rate, then the grand total with GST: on the quotation page, the PDF, the customer's link and WhatsApp. What the customer owes (balance, reminders) includes GST, and a new invoice adds GST on the quoted prices at this rate. Prices on the quotation stay without GST.

{% if boq.gst.on %}{% endif %}
{% if boq.on %}
Rate column · {{ 'shown' if boq.show_rate else 'hidden' }}

Whether their customer sees each line's rate (PDF, link, WhatsApp), or only the quantity, unit and amount. They can also change it in Settings → Quotation PDFs.

{% endif %}

{% else %}

Available once the business is running.
